# 🖼️ Image Compressor - 이미지 압축기

> 브라우저에서 이미지를 압축하고 리사이징하세요. 서버 전송 없이 100% 클라이언트에서 처리됩니다.

## ✨ 주요 기능

### 🗜️ 이미지 압축
- JPEG, PNG, WebP 포맷 지원
- 품질 조절 (10% ~ 100%)
- 실시간 압축률 확인

### 📐 리사이징
- 원하는 크기로 조절
- 비율 유지 옵션
- 픽셀 단위 정밀 조정

### 🔄 포맷 변환
- JPEG: 사진에 최적화
- PNG: 투명 배경 지원
- WebP: 최신 고효율 포맷

### 📊 압축 결과 비교
- 원본/압축 크기 표시
- 절감률 계산
- Before/After 비교 슬라이더

### 📦 배치 처리
- 여러 이미지 동시 업로드
- 일괄 압축
- **ZIP 파일로 한번에 다운로드**

---

## 🛠️ 기술 스택

| 기술 | 용도 |
|------|------|
| HTML5 Canvas | 이미지 처리 및 압축 |
| File API | 파일 읽기 및 처리 |
| Blob API | 압축 데이터 생성 |
| JSZip | ZIP 파일 생성 |
| LocalStorage | 테마 설정 저장 |

## 🎯 사용 방법

### 1. 이미지 업로드
- 드래그 앤 드롭으로 이미지 추가
- 또는 클릭하여 파일 선택
- 최대 10MB, 여러 파일 가능

### 2. 압축 설정
- **품질**: 슬라이더로 10% ~ 100% 조절
- **포맷**: JPEG, PNG, WebP 중 선택
- **리사이징**: 크기 조절 활성화 후 원하는 크기 입력

### 3. 압축 실행
- "⚡ 압축하기" 버튼 클릭
- 자동으로 압축 결과 미리보기 표시

### 4. 다운로드
- 단일 이미지: "⬇️ 다운로드" 버튼으로 저장
- **여러 이미지: "📦 ZIP으로 다운로드" 버튼으로 한번에 저장**
- 원본 파일명에 새 확장자 적용

## 💡 팁

### 최적의 품질 설정
| 용도 | 권장 품질 | 설명 |
|------|-----------|------|
| 웹 게시용 | 70-80% | 용량 절감과 품질의 균형 |
| 고품질 보관 | 85-95% | 눈에 띄는 품질 손실 없음 |
| 썸네일용 | 50-60% | 작은 크기에서 충분 |
| 최대 압축 | 30-50% | 용량 최소화 우선 |

### 포맷별 특징
- **JPEG**: 사진에 가장 적합, 투명 배경 불가
- **PNG**: 그래픽/로고에 적합, 투명 배경 지원
- **WebP**: 가장 효율적, 일부 구형 브라우저 미지원
